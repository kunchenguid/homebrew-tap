# Kun's Homebrew Tap

This repository is a general Homebrew tap for Kun Chen's apps and developer tools.

## Baby Menu

Install Baby Menu with:

```sh
brew install --cask kunchenguid/tap/baby-menu
```

Upgrade Baby Menu with:

```sh
brew update
brew upgrade --cask baby-menu
```

Baby Menu stores mutable app state in `~/.baby-menu` so generated extensions survive app upgrades.

## Firstmate 3000

Firstmate 3000 is a calm desktop first officer that runs AI crew on your own subscriptions. It is in private alpha and requires macOS Ventura or later.

Install Firstmate 3000 with:

```sh
brew install --cask kunchenguid/tap/firstmate-3000
```

Upgrade Firstmate 3000 with:

```sh
brew update
brew upgrade --cask firstmate-3000
```
